# Domain knowledge

Project-specific domain notes live here. This directory starts empty on purpose:
the template does not invent your domain.

After `/init-project` (or as the product evolves), add short markdown files for
language, invariants, and rules agents must respect — glossaries, pricing rules,
compliance constraints, entity definitions, etc.

Agents should read relevant files here before designing or implementing behaviour
that depends on domain meaning. Prefer small, named notes over one giant dump.
