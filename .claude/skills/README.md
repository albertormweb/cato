# Skills

Reusable project-specific skills for Claude Code live here. Empty in the template
on purpose — add a skill when the same workflow repeats across sessions.

Each skill is typically a folder with a skill definition file (Claude Code's
usual SKILL.md convention) and optional helpers that agents load when the task
matches. Do not put one-off task notes here; those belong in `PLANNING.md` or
`specs/`.

If you have nothing reusable yet, leave this directory as-is. Filling it later is
expected, not a gap in the framework.
